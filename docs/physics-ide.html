Physics IDE

A desktop research environment for developing and testing theoretical physics with AI assistance.

Release candidate coming soon. Physics IDE is being prepared for its first release candidate as a Linux .deb package. A download and the source repository will be linked here when it is published.

A theoretical framework is a large, interlocking body of axioms, derivations, notation and manuscript. A chat window cannot hold it, and an assistant that only sees the last few messages cannot reason about it. Physics IDE puts the theory itself in the workspace — master axiom file, chapters, notes, scripts, experiments and data — and gives its AI assistants a structured, indexed view of all of it, so a question about one derivation can be answered against the whole.

What it does

  • Theory profiles: one workspace per theory, with a master axiom file, structured manuscript chapters, a scratchpad, and linked tools, scripts and datasets.
  • Two independent AI research lanes of configurable strength, so a strong model can check a fast one, or two lines of reasoning can run side by side on the same context.
  • Project awareness built from the actual files: a generated awareness document, a theory-agnostic structural schema, and a local hybrid search index (full-text plus vector) that retrieves the relevant sections for each request.
  • Gated file access: the AI is advisory by default and can be granted write access limited to the active project root when you want it to edit the framework directly.
  • An AI Request Inspector and a context-load meter that show exactly what was sent, in what order, and what it cost in tokens — before and after each request.
  • Manuscript search with section navigation, KaTeX rendering, and Pandoc export.
  • Everything stays on the machine: SQLite indexes, local embeddings, no server of ours in the loop.

Where it stands, and a note on AI models

Version 8 is the release-candidate baseline; the work toward the first official release is production hardening and efficient project-aware AI operation. Physics IDE currently drives cloud AI providers. In day-to-day research use a serious theory consumes context quickly, and cloud token pricing makes sustained work expensive. The intended fit is a local model served through Ollama, which is not yet an option in the app but is the direction the release is heading — the retrieval and prompt-assembly work already done is what makes a local model viable for this workload.

Who it is for

Researchers and serious students developing or evaluating a theoretical framework — mainstream, hybrid or non-standard — who want AI assistance that is grounded in their own material rather than in whatever a chat model happens to recall.
